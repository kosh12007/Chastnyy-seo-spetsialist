# Active Context: Текущее состояние и активный фокус

## 1. Текущий фокус работы
* Стабилизация локального dev-окружения через Docker + Nginx.
* Устранение ошибки `403 Forbidden` при загрузке скомпилированных зависимостей Vite через реверс-прокси Nginx (порт 8085).
