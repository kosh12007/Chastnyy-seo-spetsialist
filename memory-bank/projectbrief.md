# Project Brief: Сайт частного SEO-специалиста

## 1. Общие сведения
* **Название проекта**: Сайт частного SEO-специалиста (SEO Specialist Portfolio & Lead Gen Site).
* **Назначение**: Презентационный и высококонверсионный промо-сайт для привлечения клиентов на услуги комплексного SEO-продвижения сайтов в Яндекс и Google, разовых SEO-аудитов и консультаций.
* **Целевая география**: Москва, Санкт-Петербург, регионы РФ, русскоязычный сегмент бизнеса.

---

## 2. Ключевые цели и задачи
1. **Генерация лидов и заявок (CRO)**:
   * Быстрый доступ к формам заказа звонка (`CallbackModal`) и детального обсуждения проекта (`DiscussionModal`).
   * Высокая конверсия благодаря понятным тарифам, открытому прайс-листу и коммерческим триггерам доверия.
2. **Демонстрация экспертности и результатов**:
   * Разбор реальных кейсов с графиками прироста органического трафика и позиций в ТОП-3/ТОП-10.
   * Отзывы клиентов, сертификаты и детальное описание методологии работ.
3. **Безупречные технические SEO-показатели**:
   * Максимальная скорость загрузки (Core Web Vitals: LCP < 1.5s, CLS = 0, FID/INP < 100ms).
   * Полноценная микроразметка Schema.org (`LocalBusiness`, `Article`, `FAQPage`, `BreadcrumbList`).
   * ЧПУ, канонические теги, Open Graph разметка, валидный `sitemap.xml` и `robots.txt`.
4. **Надежность и масштабируемость инфраструктуры**:
   * Docker-окружение для легкого развертывания на любом VPS/VDS.
   * Nginx в качестве реверс-прокси с SSL Let's Encrypt и gzip-компрессией.

---

## 3. Границы проекта (Scope)

### Входит в область проекта:
* Полнофункциональное SPA-приложение на React 18 + TypeScript + Tailwind CSS.
* 11 страниц (Главная, Услуги, Отдельные услуги, Цены, Кейсы, Отзывы, Обо мне, Контакты, Блог, Статьи блога, Политика конфиденциальности).
* Формы обратной связи с клиентской валидацией через React Hook Form и Zod.
* Маскирование и валидация международных номеров телефонов (`libphonenumber-js`).
* Docker Dev и Prod конфигурации с автоматизацией SSL-сертификатов.
* Батники автоматизации под Windows (`start.bat`, `stop.bat`, `REstart.bat`, `create_backup.bat`).

---

## 4. Критические ограничения и стандарты качества
1. **Языковой стандарт (ФЗ «О государственном языке РФ»):**
   * **СТРОГИЙ ЗАПРЕТ НА АНГЛИЦИЗМЫ И МАРКЕТИНГОВЫЙ СЛЕНГ** во всем клиентском интерфейсе, мета-тегах, текстах, комментариях к коду и коммитах.
   * Никаких «хаб», «оффер», «чек-лист», «краулинг», «юзабилити», «чекаут», «бэклинки», «бенчмарк», «e-commerce», «DEV», «баги» и т.д.
   * Использовать только естественный, грамотный русский язык (центр услуг, специальное предложение, список проверок, сканирование сайта, удобство для пользователей, входящие ссылки, интернет-магазины, разработчики).
   * Исключение — только необходимая международная техническая терминология: SEO, HTML, robots.txt, sitemap.xml, Schema.org, HTTP 200/301/404, Core Web Vitals, бренды Яндекс/Google/Telegram.
2. **Архитектурный стандарт услуг:**
   * Структура: «Папка сервис -> Папка комплексная услуга -> Папка подуслуга». 1 страница = 1 самодостаточный файл `index.tsx` со всей разметкой, Schema.org, FAQ и стилями.
